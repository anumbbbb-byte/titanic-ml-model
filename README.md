# titanic-ml-model
# Titanic Survival Prediction

## Project Overview

This project uses the Titanic dataset to predict whether a passenger survived or not.

## Data Preprocessing

The dataset was cleaned and prepared before applying machine learning models.

## Machine Learning Models

The following classification models were applied:

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Decision Tree
- Naive Bayes

## Model Evaluation

The accuracy of each model was calculated and compared to evaluate their performance.

## Notebook

The complete implementation is available in `titanic.ipynb`
# Make Blobs and PCA

This project demonstrates the use of `make_blobs` for generating a synthetic dataset and Principal Component Analysis (PCA) for dimensionality reduction.

## Topics Covered

- Generating data using `make_blobs`
- Data visualization
- Principal Component Analysis (PCA)
- Dimensionality reduction
- Visualizing the transformed data
